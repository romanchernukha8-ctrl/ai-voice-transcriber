# Changelog

## [1.0.0] - 2026-10-11

### Added
- React frontend and FastAPI-based microservices.
- Audio file storage with MinIO and PostgreSQL persistence.
- Asynchronous processing with RabbitMQ.
- Speech-to-text transcription using Faster-Whisper.
- Local AI text processing through Ollama.
- Local Kubernetes deployment using Minikube and Helm.
- Docker Compose configuration for local service execution.
- Persistent storage and Kubernetes health probes.
- Monitoring configuration for Prometheus, Grafana and Loki.
- GitHub Actions CI with tests, dependency scanning, Helm validation,
  Kubernetes manifest validation, and Docker image build/security checks.
- Unified local startup and shutdown scripts.
- Project architecture and requirements documentation.
